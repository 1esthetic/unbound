# Changelog

## [1.0.0] - 2026-11-07

### Added

- Selection mode: tap messages to select or deselect them.
- Range selection by tapping the first and last message.
- Delete every selected message, after a confirmation that says how many will go.
- Selection clears itself when you switch channels, so a deletion cannot target messages you are no longer looking at.
- Native row highlight behind selected messages.
- Progress toast during deletion, with a count of deleted and failed messages.
