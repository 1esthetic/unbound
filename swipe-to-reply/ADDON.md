Discord lets you swipe a message to reply to it, but not your own: on your own messages the same gesture opens the editor. This plugin makes every swipe a reply.

## What changes

- Swiping your own message replies to it instead of opening the edit box.
- Swiping anyone else's message keeps working as it did.
- Nothing else about the composer, the editor or the message menu changes.

## Details

- Works without any settings, and can be turned off at any time from the plugin list.
- iPhone, iPad and Android.
