# Nocturne

Тёмная тема для Unbound: нейтральный графит без синего оттенка, чуть темнее Discord «Darker».

## Палитра

| Роль | Цвет |
| --- | --- |
| Чат | `#121212` |
| Список каналов / ЛС | `#181818` |
| Рейл серверов | `#0c0c0a` |
| Карточки, эмбеды, поле ввода | `#1c1c1c` |
| Основной текст | `#eeeeef` |
| Приглушённый текст | `#929394` |
| Акцент (кнопки, свитчи, реакции) | `#7d7569` |
| Ссылки | `#c9b39a` |
| Упоминания | `#b08a52` |

Палитра сгенерирована тем же алгоритмом, что и официальный Theme Maker Unbound:
база `darker`, фон `#121212`, акцент `#7d7569`, упоминания `#b08a52`. Затем вручную
добавлены тёплые системные цвета iOS (`systemBlueColor` и соседние), чтобы убрать
синий тинт из нативных элементов.

## Файлы

- `manifest.json` — метаданные темы.
- `bundle.json` — палитра: `type`, `semantic`, `raw`.

## Как менять

Для быстрой правки достаточно отредактировать `bundle.json`:

- `raw.NEUTRAL_*` — фон, поверхности, текст;
- `raw.BLURPLE_*` и `raw.BLUE_NEW_*` — акцент и ссылки;
- `raw.YELLOW_*` — упоминания;
- `semantic.TEXT_LINK` — цвет ссылок.

В dev-режиме тему можно перезалить через дебаггер (`themes.reload`) или включить
заново в Unbound → Themes. Нативные цвета iOS подхватываются после перезапуска Discord.

## Нативный индикатор свайпа

Синий кружок и подложка при свайпе по сообщению рисуются нативным `DCDSwipeToReplyView`,
поэтому тема (это только данные) их не перекрашивает. Рядом лежит компаньон-плагин
`../nocturne-native`: он подменяет цвета до отрисовки и работает, только пока включена
эта тема. Если меняешь палитру темы, обнови константы `CHAT` и `ACCENT` в его `index.tsx`.
