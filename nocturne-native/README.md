# Nocturne Native

Компаньон к теме **Nocturne**. Перекрашивает нативный индикатор свайпа Discord
(`DCDSwipeToReplyView`), который тема как набор данных перекрасить не может.

- Кружок ответа: акцент темы `#7d7569`.
- Подложка свайпа: цвет чата `#121212`.
- Работает только когда включена тема `1esthetic.nocturne`; с другой темой или в светлом
  режиме ничего не трогает.

## Сборка и заливка

```bash
bun run build
bunx --bun @unbound-app/cli push . --build=false
```

`node_modules` — симлинк на `../swipe-to-reply/node_modules`, чтобы не ставить зависимости
второй раз.

## Правки

Цвета заданы константами `CHAT` и `ACCENT` в `index.tsx`. Если меняешь палитру темы,
обнови их и пересобери плагин.
